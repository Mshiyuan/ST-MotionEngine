# 动效引擎 Motion Engine

SillyTavern 扩展。统一接管酒馆界面的动画：按钮、抽屉、菜单、弹窗等改用只在合成线程执行的写法，手感风格可切换。

> 开发中（0.5.0）。

## 安装

酒馆 → 扩展 → 安装扩展，填入：

```
https://github.com/Mshiyuan/ST-MotionEngine
```

在 SillyTavern 1.15 至 1.19 上测试过。

## 功能

- **手感风格**（16 种）：
  - 平稳（不回弹）：丝滑减速、柔和淡入、利落干脆、iOS 原生、优雅慢放、呼吸舒展；
  - 弹性（有回弹）：弹簧阻尼、Material 3 Expressive、Q弹回弹、轻触果汁、果冻弹性、摆动悬挂；
  - 特效：模糊聚焦、漂浮轻盈、墨水晕开、复古阶梯。
  - 每张风格卡片画出运动曲线，并自动标出速度（快 / 中速 / 慢）和回弹程度（无 / 轻 / 强）。
  - 可以自建标签，给任意风格贴上，按标签筛选。
- **自定义风格**：以任意风格为起点，调整进场曲线（含可调弹簧、吸附）、时长、位移、横向和纵向起始缩放、变形基点、模糊、按压、依次间隔和面板开合方式，改动立即生效。可以复制、删除，按住卡片拖动排序。
- **导入码**：
  - 自定义风格：「名称：#」加 11 位，例如 `磁吸吸附：#sMcLWZLLn4h`。在「自定义」分组的「导入」卡片粘贴。
  - 分模块配置：「名称：@」加若干位（只记录改动过的项）。在分模块设置的「导入」粘贴。
  - 码里只有参数编号，导入时逐项校验范围，不包含也无法包含代码。
- **预览**：面板、按钮、开关、复选框、图标、菜单、提示、列表八个样本，分页切换，轻点演示区即播放。
- **面板开合方式**：跟随风格、垂直滑动、缩放到图标、浮起 / 下沉、侧滑、卷帘、纵向展开、淡入淡出、无动画。默认打开和关闭用同一种，也可以分开设置。
- **速度、幅度**：
  - 整体调快调慢；幅度范围 0–3。
  - 强度随面积：「越大越弱」（默认）时，按钮这类小部件效果完整，面板、长消息按面积减弱（位移、形变、晃动次数一起减弱，面积相近的消息和面板强度一致）；「统一」时全部按小部件的强度。
  - 分模块设置（默认关）：开启后在「作用范围」每一项下面单独设置幅度（0–5）和速度，可保存为多套配置，点击切换。
- **作用范围**（19 项，分 4 组，每组可一键全开 / 全关）：
  - 点按反馈：按钮按压、图标点击反馈、复选框；
  - 面板与弹出：顶栏面板与侧栏、左下角菜单、弹窗、提示条、折叠块、选择框改为页内列表（默认关，需要 Chrome / Edge 135 以上）、头像放大与成员列表；
  - 聊天：新消息、进入聊天、切换回复、思维链、编辑消息、消息「…」按钮；
  - 列表与页面：欢迎页、右栏切页、列表刷新（翻页、每页条数、标签筛选、搜索、聊天记录、背景图）。
- **扩展菜单快捷设置**（默认关，在「兼容与性能」里）：在酒馆的扩展菜单中添加入口，打开精简设置（总开关、风格、速度、幅度）。
- **兼容与性能**：暂停被面板挡住的循环装饰（默认开）、低配模式、覆盖美化动效、跟随系统和酒馆的减少动效、弹窗从点击位置展开、按压震动。
- **与原版的关系**：关闭总开关后与原版完全一致。

## 实现要点

- 只动 `opacity` 和独立的 `translate` / `scale` 属性，不改 `transform`，美化主题写死的 `transform` 照常生效。
- 图标带有以外层为参照定位的装饰（例如美化用 `::after` 画的下划线）时，只缩放图标的图形，装饰位置不变。装饰在动画途中才出现时（酒馆点击后才加 `openIcon`），在下一次绘制前把动画移到图形上。
- 美化贴图预解码：浏览器对正在做动画的新元素会延后解码大图，导致动画中贴图空白。插件在主题加载后空闲时先解码一遍。
- 背景为 `background-attachment: fixed` 的面板：动画期间换成位置和大小完全相同的普通背景，结束后换回。面板可以正常移动，背景不跳动。
- 退场时透明度匀速变化，并等关闭那一帧的样式重算过去再开始，手机掉帧时也不会一下子消失。
- 思维链和内容多的折叠块不逐帧改高度（那样每一帧都要重新排版），改用位移、缩放和裁剪。
- 选择框用浏览器自带的可自定义下拉框（`appearance: base-select`），仍是原生 `<select>`，不拦截点击。
- 打开面板时先只写不读，等打开那一帧画完再量尺寸、开始动画，不额外触发排版。
- 颜色全部取酒馆主题变量。主题的模糊底色与文字颜色对比不足时，插件的浮层和设置面板改用与文字反差足够的颜色。
- 其他插件或调试可用 `window.MotionEngine`：改完 `settings` 后调用 `apply()` 生效，`save()` 保存。
