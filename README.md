# 动效引擎 Motion Engine

SillyTavern 扩展。统一接管酒馆界面的动画：按钮、抽屉、菜单、弹窗等改用只在合成线程执行的写法，手感风格可切换。

> 开发中（0.1.0）。当前已完成：按钮按压、顶栏抽屉与侧栏、汉堡菜单与扩展菜单、新式弹窗。

## 安装

酒馆 → 扩展 → 安装扩展，填入：

```
https://github.com/Mshiyuan/ST-MotionEngine
```

需要 SillyTavern 1.13.0 或更高版本。

## 功能

- **手感风格**：日常（丝滑减速、弹簧阻尼、柔和淡入、利落干脆、iOS 原生、Material 3 Expressive）、活泼（Q弹回弹、轻触果汁）、氛围（模糊聚焦、漂浮轻盈、墨水晕开）、个性（果冻弹性、优雅慢放、复古阶梯）。
- **速度、幅度**：整体调快调慢；调整位移和缩放的幅度。
- **作用范围**：每个部件可以单独开关。
- **与原版的关系**：关闭总开关后与原版完全一致。开启酒馆的「减少动态效果」或系统的减少动效时，只保留短暂的淡入淡出。

## 实现要点

- 只动 `opacity` 和独立的 `translate` / `scale` 属性，不改 `transform`，美化主题写死的 `transform` 照常生效。
- 打开大面板时，第一帧往往要排版上百毫秒；动画在这一帧画完后才开始，不会一出现就播完。
- 抽屉不再逐帧过渡高度；关闭动画在所有浏览器上都可用。
