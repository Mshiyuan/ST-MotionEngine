# 动效引擎 Motion Engine

SillyTavern 扩展。统一接管酒馆界面的动画：按钮、抽屉、菜单、弹窗等改用只在合成线程执行的写法，手感风格可切换。

> 开发中（0.4.0）。

## 安装

酒馆 → 扩展 → 安装扩展，填入：

```
https://github.com/Mshiyuan/ST-MotionEngine
```

在 SillyTavern 1.15 至 1.19 上测试过。

## 功能

- **手感风格**：
  - 日常：丝滑减速、弹簧阻尼、柔和淡入、利落干脆、iOS 原生、Material 3 Expressive；
  - 活泼：Q弹回弹、轻触果汁；
  - 氛围：模糊聚焦、漂浮轻盈、墨水晕开、呼吸舒展；
  - 个性：果冻弹性、优雅慢放、复古阶梯、故障闪现。
  - 每种风格有自己的打开和关闭方式。设置里每张风格卡片画出这种风格的运动曲线。
- **自定义风格**：以任意风格为起点，调整进场曲线（含可调弹簧）、时长、位移、缩放、模糊、按压、依次间隔和面板开合方式，改动立即生效。
- **分享设置**：风格、速度、幅度、开合方式、分模块的值和自定义风格可以导出为一段文字，别人粘贴即可导入。导入时只读取数值，不运行代码。
- **预览**：面板、按钮、开关、复选框、图标、菜单、提示、列表八个样本，分页切换，轻点演示区即播放。
- **面板开合方式**：跟随风格、垂直滑动、缩放到图标、浮起 / 下沉、侧滑、卷帘、淡入淡出、无动画。默认打开和关闭用同一种，也可以分开设置。
- **速度、幅度**：
  - 整体调快调慢；幅度范围 0–3。
  - 强度随面积：「越大越弱」（默认）时，按钮这类小东西效果最明显，面板、长消息按面积减弱；「统一」时全部按小部件的强度。
  - 分模块设置（默认关）：开启后，每个模块单独设置幅度（0–5）和速度。
- **作用范围**（每项可单独开关）：按钮按压、图标点击反馈、复选框、顶栏面板与侧栏、左下角菜单、弹窗、提示条、折叠块、选择框改为页内列表（默认关，需要 Chrome / Edge 135 以上）、新消息、欢迎页、思维链、切换回复、细节交互（进入聊天、编辑消息、右栏切页、角色列表翻页、头像放大）。
- **兼容与性能**：面板预渲染（默认开）、低配模式、覆盖美化动效、跟随系统和酒馆的减少动效、弹窗从点击位置展开、按压震动。
- **与原版的关系**：关闭总开关后与原版完全一致。

## 实现要点

- 只动 `opacity` 和独立的 `translate` / `scale` 属性，不改 `transform`，美化主题写死的 `transform` 照常生效。
- 图标带有以外层为参照定位的装饰（例如美化用 `::after` 画的下划线）时，只缩放图标的图形，不让装饰跑位。
- 美化贴图预解码：浏览器对正在做动画的新元素会延后解码大图，导致动画中贴图空白。插件在主题加载后空闲时先解码一遍。
- 背景为 `background-attachment: fixed` 的面板：动画期间换成位置和大小完全相同的普通背景，结束后换回。面板可以正常移动，背景不跳动。
- 退场时透明度匀速变化，并等关闭那一帧的样式重算过去再开始，手机掉帧时也不会一下子消失。
- 思维链和内容多的折叠块不逐帧改高度（那样每一帧都要重新排版），改用位移、缩放和裁剪。
- 选择框用浏览器自带的可自定义下拉框（`appearance: base-select`），仍是原生 `<select>`，不拦截点击。
- 打开面板时先只写不读，等打开那一帧画完再量尺寸、开始动画，不额外触发排版。
- 颜色全部取酒馆主题变量。
- 其他插件或调试可用 `window.MotionEngine`：改完 `settings` 后调用 `apply()` 生效，`save()` 保存。
