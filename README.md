# 动效引擎 Motion Engine

SillyTavern 扩展。统一接管酒馆界面的动画：按钮、抽屉、菜单、弹窗等改用只在合成线程执行的写法，手感风格可切换。

> 开发中（0.3.0）。

## 安装

酒馆 → 扩展 → 安装扩展，填入：

```
https://github.com/Mshiyuan/ST-MotionEngine
```

需要 SillyTavern 1.13.0 或更高版本。

## 功能

- **手感风格**：日常（丝滑减速、弹簧阻尼、柔和淡入、利落干脆、iOS 原生、Material 3 Expressive）、活泼（Q弹回弹、轻触果汁）、氛围（模糊聚焦、漂浮轻盈、墨水晕开）、个性（果冻弹性、优雅慢放、复古阶梯）。每种风格有自己的打开和关闭方式。
- **面板开合方式**：顶栏面板和侧栏的开合方式：跟随风格、垂直滑动、缩放到图标、浮起 / 下沉、侧滑、卷帘、淡入淡出、无动画。默认打开和关闭用同一种，也可以分开设置。
- **作用范围**：按钮按压、图标点击反馈、顶栏面板与侧栏、左下角菜单、弹窗、提示条、折叠块与下拉框、新消息、切换回复、细节交互（进入聊天、思维链、编辑消息、右栏切页、头像放大），每项可单独开关。
- **速度、幅度**：整体调快调慢；幅度 0–3。大面板回弹可选「减弱」（默认）或「与小部件一致」。
- **预览**：设置里每张风格卡片画出这种风格的运动曲线；预览台有面板、按钮、开关、图标、菜单、提示、列表几个样本，轻点即演示。
- **兼容与性能**：面板预渲染（默认开）、低配模式、覆盖美化动效、跟随系统和酒馆的减少动效、下拉框展开动画（Chrome / Edge 135 以上）。
- **与原版的关系**：关闭总开关后与原版完全一致。

## 实现要点

- 只动 `opacity` 和独立的 `translate` / `scale` 属性，不改 `transform`，美化主题写死的 `transform` 照常生效。
- 美化贴图预解码：浏览器对正在做动画的新元素会延后解码大图，导致动画中贴图空白。插件在主题加载后空闲时先解码一遍。
- 背景为 `background-attachment: fixed` 的面板只做淡入淡出，不移动元素，背景不跳动。
- 退场时透明度匀速变化，并等关闭那一帧的样式重算过去再开始，手机掉帧时也不会一下子消失。
- 下拉框用浏览器自带的可自定义下拉框（`appearance: base-select`），仍是原生 `<select>`，不拦截点击。
- 打开面板时先只写不读，等打开那一帧画完再量尺寸、开始动画，不额外触发排版。
- 颜色全部取酒馆主题变量。
